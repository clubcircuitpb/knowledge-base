To sign in, go to [app.clubcircuitpb.com/login](https://app.clubcircuitpb.com/login), enter your email and select **Email me a sign-in code**, then type the 6-digit code we email you and select **Sign in**. There's no password to remember.

{/* src: leagues-app src/app/login/page.tsx:72,126,130; src/app/login/code/code-form.tsx:41,57 */}

**Before you begin**

- Have your email inbox open on the same phone or computer, or nearby. The code comes by email.
- New to ClubCircuit? You don't need a separate sign-up (also called creating an account or registering an account). Signing in with your email for the first time creates your account. {/* src: src/lib/auth/config.ts:18-19 (sign-up is open); docs/adr/0001-public-consumer-auth.md */}

## Sign in with an emailed code

<Steps>
  <Step title="Open the sign-in page">
    Go to [app.clubcircuitpb.com/login](https://app.clubcircuitpb.com/login), or select **Sign in** at the top of any ClubCircuit page.
    {/* src: src/app/login/page.tsx:72 (h1 "Sign in"); src/components/shell/public-frame.tsx (header Sign in link) */}
  </Step>
  <Step title="Enter your email">
    Type your address in **Email address**, then select **Email me a sign-in code**.
    {/* src: src/app/login/page.tsx:126,130 */}
  </Step>
  <Step title="Find the email">
    Open the email with the subject **Your ClubCircuit sign-in code**. The code is in large type in the email. The email has no link to tap.
    {/* src: src/lib/auth/sign-in-code.tsx:31 (subject "Your ClubCircuit sign-in code: {code}"), :45-47; docs/adr/0027-email-code-sign-in.md */}
  </Step>
  <Step title="Type the code">
    Back on the **Enter your code** page, type the 6 digits into **6-digit code**. On most phones, the keyboard offers to fill in the code from the email for you.
    {/* src: src/app/login/code/page.tsx:53; code-form.tsx:41,46-47 (inputMode numeric, autoComplete one-time-code) */}
  </Step>
  <Step title="Select Sign in">
    Select **Sign in**.
    {/* src: src/app/login/code/code-form.tsx:57 */}
  </Step>
</Steps>

**Result:** You're signed in and taken to your ClubCircuit home, or back to the page that sent you to sign in, such as a club's invitation link. If you're new and haven't registered for a season yet, you're taken to registration instead. You stay signed in on that device until you sign out. {/* src: src/lib/nav/landing.ts:27-34 (landing; no roles or roster → /join → /register); src/app/login/code/actions.ts (callbackUrl = safe next); src/lib/auth/sign-in-flow.ts (signInPath keeps next); src/lib/auth/config.ts:113 (database session) */}

<Note>
  Each code works once and expires 10 minutes after we send it. The **Enter your code** page shows how long you have. {/* src: src/lib/auth/sign-in-code.tsx:13 (SIGN_IN_CODE_TTL_MINUTES = 10), :49-50; src/app/login/code/page.tsx:55 */}
</Note>

## Why isn't this working?

### I didn't get the email
**Cause:** It went to your spam or junk folder, or the address has a typo.
**Fix:** Check spam and junk first, and search your inbox for "ClubCircuit sign-in code". If it's not there, check the address shown on the **Enter your code** page. If it's right, select **Send me a new code**. If it's wrong, select **Use a different email** and enter it again. {/* src: src/app/login/code/page.tsx:55 (address shown), :77-79 ("Didn’t get it, or it expired? Check spam first." / "Send me a new code"), :86 ("Use a different email") */}

### "That code didn’t work. It may have a typo, or it may have expired."
**Cause:** The code was mistyped, it's more than 10 minutes old, it came from an older email, or you already used it. You stay on the **Enter your code** page, so you don't need to type your email again.
**Fix:** Check the most recent email from us and type that code again. If it has expired, select **Send me a new code** and use the code in the new email. {/* src: src/lib/auth/sign-in-flow.ts:59-60 (WRONG_CODE_MESSAGE); src/app/login/page.tsx:56-59 (wrong code → back to /login/code with email); src/app/login/code/page.tsx:63,79; src/lib/auth/sign-in-code.tsx:49 (single use) */}

### "That code was wrong or has expired. Enter your email to get a new one."
**Cause:** Your code didn't work and the sign-in page couldn't send you back to the code page, usually because more than 10 minutes passed since you entered the code.
**Fix:** Enter your email again and select **Email me a sign-in code**. Use the code in the newest email. {/* src: src/app/login/page.tsx:45 (fallback when no pending sign-in); src/lib/auth/sign-in-flow.ts (cookie lifetime = code lifetime) */}

### "We sent a new code."
**Cause:** You selected **Send me a new code**. This isn't an error.
**Fix:** Use the code in the most recent email. Codes from earlier emails may no longer work. {/* src: src/app/login/code/page.tsx:67 */}

### "Enter the 6-digit code from the email."
**Cause:** What you typed isn't 6 digits.
**Fix:** Copy the code exactly as it appears in the email. Spaces are fine. {/* src: src/app/login/code/actions.ts:27 */}

### "That’s a lot of codes for one address."
**Cause:** You've asked for several codes for the same email address in a short time.
**Fix:** Check your inbox, including spam, and use the most recent code that already arrived. If you still need a new one, the message tells you how long to wait before you can request it. {/* src: src/lib/auth/sign-in-flow.ts:27-28 (tooManyCodesMessage, real wait); src/app/login/page.tsx; src/app/login/code/actions.ts (resend, same limit); src/lib/rate-limit/limiter.ts (magicLinkPerEmail) */}

### "Too many tries with that code. Wait …, then request a new code."
**Cause:** A code was entered incorrectly several times in a row, for your email address or from your connection. Every code check counts, however it reaches ClubCircuit.
**Fix:** Wait for the time the message gives, then select **Send me a new code** on the **Enter your code** page and use the new code. {/* src: src/lib/auth/route-limits.ts:6-16,47-52 (signInCodePerEmail, signInCodePerIp); src/app/api/auth/[...nextauth]/route.ts; src/app/login/code/page.tsx:79 */}

### "Enter a valid email address."
**Cause:** The address is missing part of it, like the `@` or the ending.
**Fix:** Check the address and try again. {/* src: src/app/login/page.tsx:100 */}

### "Something went wrong. Start again from the sign-in page."
**Cause:** The code page lost track of your email address, often because the page was opened from an old tab.
**Fix:** Go back to [the sign-in page](https://app.clubcircuitpb.com/login) and start again. {/* src: src/app/login/code/actions.ts:27 */}

### I'm looking for a "Sign in with Google" button
**Cause:** ClubCircuit signs you in with an emailed code. There's no Google option on the sign-in page.
**Fix:** Use the email address on your Google account, or any email you check. {/* src: src/app/login/page.tsx (no Google provider button); docs/adr/0027-email-code-sign-in.md */}
