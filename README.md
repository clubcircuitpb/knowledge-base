# ClubCircuit help center

Help for ClubCircuit players, team captains, and club admins and owners. Published by
[Mintlify](https://mintlify.com) from `main`.

- **Writing or editing an article:** read [`AGENTS.md`](AGENTS.md) first. Every step must come
  from the app itself, never from memory.
- **Preview locally:** `npm i -g mint`, then `mint dev` in this folder.
- **Check before pushing:** `mint validate` and `mint broken-links`.
- **Publishing:** merging to `main` publishes. Merge when the matching app release is promoted to
  production, not before.

Questions: support@clubcircuitpb.com
